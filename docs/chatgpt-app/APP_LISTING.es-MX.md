# Kupuri OMA para ChatGPT - borrador privado

**Nombre:** Kupuri OMA

**Descripción corta:** Convierte una idea en un brief visual bilingüe y encuentra una base para crearla.

**Descripción:** Describe el sitio o experiencia que necesitas. Kupuri OMA organiza la intención, busca referencias por industria y estilo, y devuelve un brief en español de México listo para revisar, con inglés opcional. Antes de publicar, compartir o gastar, tú confirmas.

**Primeros mensajes sugeridos**

- Prepara un sitio para mi restaurante en Ciudad de México.
- Encuentra una plantilla editorial y crea un brief bilingüe.
- Revisa este componente con las reglas de diseño de OMA.

**Acción principal:** Preparar y previsualizar. **No promete:** publicación, compra o despliegue automático.
