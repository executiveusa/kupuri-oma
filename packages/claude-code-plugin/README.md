# Kupuri OMA for Claude Code

Vista previa privada. Instala el directorio como plugin local y usa `/oma-brief` para preparar un brief en español primero e inglés después. El plugin no publica, cobra ni comparte.

## Desarrollo local

```bash
claude --plugin-dir ./packages/claude-code-plugin
```

Conecta el MCP generado por `oma mcp-config` para búsqueda y auditoría. Las acciones que cambian estado siguen requiriendo revisión humana.
